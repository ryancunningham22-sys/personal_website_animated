# Ryan Cunningham — Personal Portfolio

An interactive portfolio highlighting my experience, education, and projects in sales and industrial distribution.

Live website: https://ryan-cunningham-portfolio.duderyanmc.chatgpt.site

## Features

- Texas-inspired desert roadmap with scroll-linked motion
- Navigation between seven portfolio sections
- Responsive layouts and reduced-motion support
- Safran carrier scorecard and corporate gifting capstone case studies
- Relevant coursework, résumé PDF, and illustrated capstone report

## Run locally

This is a static HTML, CSS, and JavaScript website. No build step or dependencies are required.

Serve this folder with any static web server, for example:

```sh
python -m http.server 5174
```

Then open http://localhost:5174.

## Files

`index.html` contains the portfolio content. `journey.js` manages scrolling and map navigation. The CSS files define the layout, personalization, and desert theme. `images/` contains the visual assets.

Photos, graphics, and documents are included as portfolio assets. Third-party assets retain their respective ownership; no license for redistribution is implied.
